# homework-FHM-5

# Высшая математика РПО — Матрицы и операции над матрицами

## 1. Аналитическая часть

Дано:

Матрица A:

```text
| 1  2 |
| 3  0 |
```

Матрица B:

```text
|  4  1 |
| -2  5 |
```

Найти: `C = (A + B^T) · A`

### Шаг 1. Транспонирование матрицы B

Строки матрицы становятся столбцами.

```text
B^T = | 4  -2 |
      | 1   5 |
```

### Шаг 2. Сложение матриц

Складываем соответствующие элементы матриц A и B^T.

```text
A + B^T = | 1+4  2+(-2) |
          | 3+1  0+5    |

A + B^T = | 5  0 |
          | 4  5 |
```

### Шаг 3. Умножение матриц

Умножаем строки первой матрицы на столбцы второй.

```text
C = | 5  0 | · | 1  2 |
    | 4  5 |   | 3  0 |
```

Вычисляем элементы:

- `c11 = 5·1 + 0·3 = 5`
- `c12 = 5·2 + 0·0 = 10`
- `c21 = 4·1 + 5·3 = 19`
- `c22 = 4·2 + 5·0 = 8`

### Ответ

```text
C = |  5  10 |
    | 19   8 |
```
